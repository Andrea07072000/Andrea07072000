# Andrea Cavazzini

I build **S.T.A.R.** (Systems, Testing, Assurance & Reliability): tooling that links every requirement to
the tests that verify it, and every result to an evidence record that someone else can regenerate.

> A result is either verified, or it says why it is not.

### What I work on

- **Requirement-to-evidence traceability**: requirements, tests and execution results in one chain, with the
  gaps shown instead of hidden.
- **Reproducible verification**: evidence packages with SHA-256 digests, recorded environments, and
  reproduction on a clean machine.
- **Time for space systems**: leap seconds, TAI/TT/GPS time, CCSDS time codes, with explicit validity domains.
